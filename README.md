# videomoon（Android）

好きな曲の好きな部分を流しながら、なめらかな60fpsで撮れる動画カメラ。
動画に入るのは流した音楽だけで、周りの音やマイクの音は一切入りません。

## できること

**撮影**
- 60 / 30 / 24 fps（端末が対応していない場合は対応する最大値に自動で落とし、画面でお知らせ）
- 720p / 1080p / 4K、縦・横
- 録画ボタンを押すと、選んだクリップの音楽と録画が同時に始まり、クリップの終わりで自動停止
- 録画ボタンはクリップの進み具合を月の満ち欠けで表示
- プリロール：開始位置の少し前から音楽を流し、開始位置から録画
- カウントダウン（3 / 5 / 10秒）、連続撮影、撮影直後の確認画面（その場で撮り直し）
- 写真モード
- 前面・背面カメラ切替、ピンチでズーム、タップでピント、ライト

**プロ設定（Blackmagic Camera風）**
- ISO・シャッタースピード（角度表示つき）・ホワイトバランス・露出補正・フォーカスを個別にオート/マニュアル
- フリッカー低減（50Hz / 60Hz）と、ちらつく値を選んだときの警告・ワンタップ修正
- プリセット：暗いステージ / ペンライト / 屋内照明 / 屋外
- ヒストグラム、ゼブラ、フォーカスピーキング、グリッド、実測fps表示

**音源**
- 端末のファイル（MP3・M4A・AAC・WAV・FLAC・OGGなど）、動画ファイルの音声、ほかのアプリの「共有」から追加
- 波形を見ながら範囲を切り取り、±0.1秒単位の微調整、再生中に「ここで開始/終了」
- 練習用のスロー再生（0.5× / 0.75×）、ループ、フェードイン/アウト
- 1曲に何個でもクリップを保存

**ライブラリ**
- テイクはアプリ内に何本でも保存（クリップごとに「テイク 1, 2, 3…」）
- 書き出し：MP4（H.264 / HEVC）で「ムービー/videomoon」へ。写真は「ピクチャ/videomoon」
- 2つのテイクを左右に並べて同時再生（比較）、まとめて書き出し・削除
- 音ズレ補正（±300ms）は再生と書き出しの両方に反映

## しくみ（音声がきれいに入る理由）

マイク権限を要求せず、**無音の映像だけを録画**します。録画開始の瞬間に曲のどこが鳴っていたかをミリ秒単位で記録し、

- アプリ内の再生：無音の映像と曲の該当区間を `MergingMediaSource` で同期再生
- 書き出し：Media3 Transformer で映像（そのままのfps）と曲の区間を1本のMP4に合成

するので、動画の音はデジタル音源そのまま。スピーカーの反響や歓声は入りません。

| ファイル | 役割 |
|---|---|
| `camera/CameraEngine.kt` | CameraX + Camera2。fps固定、マニュアル露出、フリッカー対策、実測fps |
| `camera/RecordController.kt` | 音楽再生と録画開始の同期、自動停止 |
| `camera/Exposure.kt` | ISO/シャッターの段、フリッカー安全なシャッター計算、プリセット |
| `media/Exporter.kt` | 合成書き出し、アプリ内再生用のMediaSource |
| `media/FadeAudioProcessor.kt` | 書き出し時のフェード |
| `media/MediaTools.kt` | 取り込み、波形デコード、サムネイル、ギャラリー保存 |
| `ui/*` | Jetpack Composeの各画面 |

## ビルド方法

### A. Android Studio（おすすめ）
1. Android Studio（Ladybug 以降）で このフォルダを「Open」
2. Gradle の同期が終わったら ▶ Run（実機をUSB接続、または「Build › Build APK(s)」）

### B. GitHub Actions（PCにAndroid Studioがなくても可）
1. このフォルダをGitHubのリポジトリにpush
2. 「Actions」タブ › **Build APK** が自動で走る
3. 終わったら実行結果の「Artifacts」から `videomoon-debug-apk` をダウンロード → Android端末にインストール

※ この一式は、Android SDKに接続できない環境で書いたため、まだ一度もコンパイルしていません。最初のビルドでエラーが出たら、そのログを貼ってもらえればすぐ直します。

## 動作条件
- Android 10 以上
- 60fpsは端末のカメラが対応している場合のみ（多くの中〜上位機種は1080p/60fpsに対応）
- ISO・シャッターの手動設定は、カメラが MANUAL_SENSOR に対応している端末のみ（非対応端末では露出補正とオートで撮影）

## ストリーミング・YouTubeの音源について
Spotify・Apple Music・YouTube Music などの曲や YouTube の音声を直接取り込む機能は入れていません。これらは暗号化（DRM）や利用規約でアプリからの切り出しが禁止されており、日本の著作権法でも保護技術を回避した録音は私的利用でも違法になるためです。自分で購入・保存した音声ファイル（iTunes・mora・Bandcamp などで買ったファイルを含む）なら、そのまま取り込めます。

## prototype/
`prototype/index.html` はブラウザで動く画面プロトタイプです。GitHub Pages などHTTPSで公開してiPhoneやPCで開くと、実際のカメラを使って「音楽を流しながら撮影→保存」まで試せます（ブラウザの制約で60fpsにならない端末もあります）。
